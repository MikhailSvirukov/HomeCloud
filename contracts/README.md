# Published cross-workstream contracts

Place stable public protocol, API, and trait contracts here when more than one workstream needs them. Every agent may read these published contracts. Keep private implementation details in the owning workstream directory. A contract change is coordinated through an issue/PR and reviewed by its owning workstream.

[`wire-v1.md`](wire-v1.md) is the published wire contract for protocol version 1; it restates the wire representation fixed by its cited SRS requirements for the headers, result envelope, topology answer, and inter-server message types, and records what remains unfixed.
