# Distributed storage-node workstream

An unavailable `io_uring` syscall in the agent container is an execution-environment limitation affecting specific runtime checks. Record the exact failure and affected requirement IDs, then continue independent implementation and test preparation. Do not require running the storage process locally before proceeding: tests run in PR CI. Required real-backend checks need an io_uring-capable CI runner; route shared CI changes to dedicated-server. Do not skip required checks, claim unverified backend integration is complete, or silently introduce a shipping fallback backend. Apply the global stop conditions to the workstream as a whole.

Every distributed-server process is a full Raft voting node running its own OpenRaft consensus instance. Read the [storage-cluster SRS](../../docs/specification-v1/storage-cluster.md) before planning, implementation, or review. Own the executable integration of leader election, direct Raft RPC handling, persistent Raft state, and application of committed entries to the state machine (`FR-CL-001`, `FR-CL-006`, `FR-CL-009/010`, `FR-CL-016/017`, `FR-CL-020`, `FR-CL-030/031`, `NFR-MAINT-001`–`NFR-MAINT-004`). The dedicated server is outside Raft membership. Keep separate blob replication as required by `FR-CL-011`. Track consensus requirements as unfinished until the runtime is wired and required PR CI verifies its behavior; transport framing, interfaces, and mocks alone do not complete them.

Read and follow [global agent instructions](../../docs/agent-global.md). Work only in `distributed-server/`. Before editing Rust, read the repository-root `AGENTS.md` and follow its Rust practices. Do not amend, rebase, or force-push existing history. Normal additive commits and authorized PR merges are allowed. Do not inspect Android, dedicated-server, or test-harness implementation source; use the v1 specification and published contracts. Follow [the distributed-server agent brief](../../docs/agent-distributed-server.md) and [the v1 specification](../../docs/specification-v1.md). Scope is the Rust storage node, direct encrypted node-to-node Raft and blob replication, the actor model, frame-only TCP actors, dedicated `io_uring` thread, bounded payload buffer pools, and server tests. Coordinate shared protocol changes through issues/PRs.
