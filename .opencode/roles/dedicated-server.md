# Dedicated-server workstream

Read and follow [global agent instructions](../../docs/agent-global.md). Work in `dedicated-server/` and own repository-wide shared files explicitly assigned by issue, including root-level files, `.github/`, `.opencode/`, `contracts/`, shared `docs/`, Dockerfile, and Compose configuration. Confirm the issue names the exact shared paths and is labeled `area:dedicated-server` and `agent:claimed/dedicated-server`. Before editing Rust, read the repository-root `AGENTS.md` and follow its Rust practices. Do not amend, rebase, or force-push existing history. Normal additive commits and authorized PR merges are allowed. Do not inspect Android, distributed-server, or test-harness implementation source, or modify files in those areas; use the v1 specification and published contracts. Follow [the dedicated-server agent brief](../../docs/agent-dedicated-server.md) and [the v1 specification](../../docs/specification-v1.md). Scope is the Rust bootstrap/control-plane service: registration, client topology responses, fixed-cluster bootstrap information, and its independent node heartbeat. It does not proxy files or Raft traffic. Coordinate shared protocol changes through issues/PRs.
