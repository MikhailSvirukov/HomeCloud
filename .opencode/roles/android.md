# Android workstream

Read and follow [global agent instructions](../../docs/agent-global.md). Work only in `android/` and do not inspect server or test-harness implementation source. Use the relevant skill from [Kotlin Agent Skills](https://github.com/Kotlin/kotlin-agent-skills) when it matches the task; consult its [README](https://github.com/Kotlin/kotlin-agent-skills/blob/main/README.md) and do not apply migration-specific skills unless the project is actually migrating. The Android workstream must not inspect server or test-harness implementation source; use the v1 specification and published contracts. Follow [the Android agent brief](../../docs/agent-android.md) and [the v1 specification](../../docs/specification-v1.md). The upstream Kotlin skill repository currently contains task-specific Kotlin tooling skills, not a general Android/Compose skill; select only a matching skill, such as AGP 9 migration when that migration is actually part of the task. Scope is the Kotlin/Jetpack Compose Android client, Android permission minimization, media discovery, background upload, client crypto/protocol integration, and Android tests. Coordinate shared protocol changes with the server workstreams through issues/PRs; do not invent incompatible wire behavior locally.
