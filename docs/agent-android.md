# Роль рабочей области: Android

## Назначение

Эта рабочая область отвечает за Android-клиент HomeCloud и его Android-тесты. Её нормативные требования находятся в [общем дизайне и межобластных требованиях](specification-v1.md) и в [SRS Android-области](specification-v1/android.md). SRS — единственный источник требований к функциям, качеству, ограничениям и критериям проверки.

Используй Kotlin и Jetpack Compose в соответствии с SRS, root `AGENTS.md` и проектными настройками, когда они появятся. Учитывай соответствующие Kotlin Agent Skills из [README проекта skills](https://github.com/Kotlin/kotlin-agent-skills/blob/main/README.md); не применяй миграционные инструкции, если миграция не входит в задание.

## Границы ответственности

Работай только в `android/`, кроме явно назначенных общих файлов. Не читай исходники серверов или тестовой среды. Для сетевого поведения используй SRS и опубликованные контракты. Несогласованные изменения протокола проводи через отдельное согласование требований и контрактов с владельцами областей.

## Правило постановки и выполнения задач

Каждая задача реализации должна ссылаться на точные ID и редакции требований SRS, которые она выполняет; тестовая задача также указывает связанные `TST` требования. Не выводи поведение продукта из этого брифа, GitHub issue, комментария ревью или ежедневной заметки. Если нужного требования нет, оно неполно или конфликтует с другим, сначала подготовь изменение SRS отдельной задачей; реализацию начинай после слияния этого изменения.
